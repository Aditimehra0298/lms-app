# LMS App

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Database (MySQL)

This LMS uses **MySQL**. **phpMyAdmin is not required.** You may install it **for safety / backups only**.

- Management FAQ (for bosses / auditors): [`docs/DATABASE_FOR_MANAGEMENT.md`](docs/DATABASE_FOR_MANAGEMENT.md)
- Setup with Workbench: [`docs/MYSQL_WORKBENCH.md`](docs/MYSQL_WORKBENCH.md)
- In the admin panel: **Settings → Database**
